01v3.66 更新内容

① 三版发布：M 轻量（仅 HIC）、R 标准（HIC + Python）、X 全能（HIC + Python + C++）。

② 编译 Python / C++ 为 HTML：用 py:( … )end / cpp:( … )end 包裹，HIC 内置转译器把它们编译成 HTML。这里的“能力”不是调用官方库，而是让 HIC 支持编译这些语言，完全自包含：导出页不引用任何外部库 / CDN / 网址，M/R/X 按版本各自开放可编译的语言。

02离线单文件版

「离线单文件版」是把网页端 IDE 的 HTML、CSS 与全部脚本（语言引擎、数据层、界面逻辑）打包成一个自包含的 .html。双击即可在浏览器（或 WebView）中运行，无需网络、编译更快，是安卓端与电脑端安装包的运行内核。本页新提供 HiCode-v3.66X / R / M-offline.html 三档最新内核。

03GitHub Releases · 默认发布渠道

自 v3.01 起，每个新版本都会基于 Git Tag 在 GitHub Releases 默认发布（含三档离线单文件版 / 源码 / 后续原生安装包）。前往 github.com/HiCodeHC/HiCodeHC.github.io/releases 可查看本版本的所有发布附件与更新说明。

04打包为 .apk（安卓端）

用 Capacitor 把离线单文件封装为原生 Android 应用（WebView 壳）：

npm init -y && npm i @capacitor/core @capacitor/android @capacitor/cli
cp 下载的离线单文件.html www/index.html
npx cap init HiCode com.hicode.ide
npx cap add android
cd android && ANDROID_HOME=/path/to/sdk ./gradlew assembleDebug  # 产出 app-debug.apk

05打包为 .exe（电脑端）

用 Electron + electron-builder 打包为 Windows 便携版：

npm init -y && npm i electron electron-builder --save-dev
# 写 main.js 加载本地 index.html
# 配置 package.json 的 "build" 字段
npx electron-builder --win portable --x64  # 产出 HiCode.exe
