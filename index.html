Core Features

一套语言，贯通前后端

HiCode 的核心设计：少即是多——用最简单的语法，覆盖最完整的开发链路。

🧩

前后端同时开发

同一套 HIC 语法写界面与逻辑，数据天然互通，不再来回切换语言与框架。

🎨

图形化搭前端

place 名 at (x, y) 声明式定位 + 界面元素配置，所见即所得。

💬

简易语法写后端

cf 名 … stop 事件块、let … be 赋值、say 输出——自然语言般的逻辑。

🔧

编译 Python / C++

R / X 版支持 py:( … )end、cpp:( … )end，把它们编译为 HTML，零外部依赖。

📱

一次编写 · 三端运行

网页端在线体验、Windows 便携 .exe、Android .apk——同一个离线单文件内核。

⚡

解释型 · 即时反馈

写一行跑一行，预览随改随更，不用重启、不用重新编译整个项目。

FAQ

常见问题

关于 HiCode H1.00 你可能想知道的事。

HiCode H1.00 现在可以下载使用吗？+
可以。H1.00 提供 M 轻量 / R 标准 / X 全能 三档，支持网页端在线体验、Windows 便携 .exe、Android .apk 三种形态。X 版可把 py:( … )end、cpp:( … )end 编译为 HTML，零外部依赖。下载页有全部入口。
完全没有编程基础，真的能上手吗？+
这正是 HiCode 的设计目标：图形化界面创建前端、接近自然的简易代码编写后端。学习中心有分章节教程与可下载的练习文件，跟着走一遍就能写出第一个应用。
HiCode 是免费的吗？开源吗？+
是的，HiCode 以开源方式发布，代码托管在 GitHub。我们坚持开放、可自由使用与二次开发的原则。
M / R / X 三档有什么区别？该选哪个？+
M 轻量：仅 HIC 内核，最精简，适合纯 HIC 开发。
R 标准：+ Python 编译为 HTML，适合想在 HIC 里嵌入 Python 的用户。
X 全能：+ Python + C++ 编译为 HTML，最完整。
不确定就从 X 开始，网页端顶栏随时可切换。
我可以如何参与 HiCode 的成长？+
欢迎通过 hicodehc@outlook.com 提出想法与建议，或直接在 GitHub 仓库提 Issue / Pull Request。
