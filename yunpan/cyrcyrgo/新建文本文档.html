2006 年入选首批国家级非物质文化遗产。 - 泸州老窖是中国浓香型白酒代表，酿造技艺始于秦汉、兴于唐宋、 定形成熟于元明清三代。 - 核心技艺：泥窖制作维护、大曲药制作鉴评、原酒酿造摘酒、 洞藏陈酿、勾兑尝评等。 2. 1573 国宝窖池群 - 始建于明万历元年（1573 年），由舒承宗建造。 - 连续使用至今从未间断，窖泥微生物不断驯化富集，被誉为“活文物”。 - 与酿造技艺共同构成行业独有的“双国宝”殊荣。 - 全国重点文物保护单位。 3. “看花摘酒” - 蒸馏取酒时，匠人凭酒花大小与停留时间判断酒精浓度， 以掌握取酒时机，是传统酿造技艺中最具经验的环节之一。 来源：中国非物质文化遗产网、泸州老窖官网。 -------------------------------------------------------- 三、非遗技艺 -------------------------------------------------------- 1. 分水油纸伞制作技艺 - 始于明末清初，至今 400 余年。 - 2008 年列入第二批国家级非物质文化遗产。 - 伞骨选用海拔 800 米以上深山老楠竹，全伞需经 96 道工序。 - 被誉为“中国民间伞艺的活化石”。 - 国家级传承人：毕六福（毕家第六代传人）。 2. 先市酱油酿造技艺 - 始于明末清初，传承 280 余年。 - 2014 年入选第四批国家级非物质文化遗产。 - 酿造用水取自赤水河畔地下水，黄豆产自河畔， 采用百年晒露发酵工艺。 - 产品特点：酱香浓郁、色泽棕红、挂碗不沾碗、久储不变质。 3. 古蔺郎酒传统酿造技艺 - 2008 年入选第二批国家级非物质文化遗产。 - 遵循“端午制曲”“重阳投粮”时令。 - 坚守传统大曲坤沙“12987”工艺，是酱香型白酒酿造文化的重要代表。 来源：中国非物质文化遗产网、新华网、泸州市人民政府官网。 -------------------------------------------------------- 四、民俗与表演 -------------------------------------------------------- 1. 雨坛彩龙 - 2006 年首批国家级非物质文化遗产，被誉为“东方活龙”。 - 表演重在一个“活”字，追求“人龙合一”。 - 龙头造型依据泸县龙脑桥龙头设计，龙尾呈鲢鱼状。 - 经典套路：龙出洞、龙抢宝、龙脱衣、龙叹气、太子骑龙等数十种。 2. 古蔺花灯 - 2014 年入选第四批国家级非物质文化遗产。 - 流行于古蔺县一带，表演风格“要逗要笑、要拽要闹、要唱要跳”。 - 主要角色为“唐二”与“幺妹”，幺妹通常由男子扮演， 称为“童子扮幺妹”。 3. 泸县九大碗 - 川南农村传统宴席形式，源于明清“湖广填四川”时期的田席。 - 以猪、鸡、鸭为主料，采用“三蒸九扣”技法， 体现“清鲜纯厚、醇浓并重”的泸菜风味。 - 2024 年获省级宴席类一等奖。 来源：中国非物质文化遗产网、泸州市人民政府官网、央广网。 -------------------------------------------------------- 五、文物古迹 -------------------------------------------------------- 1. 泸县宋代石刻博物馆 - 国内首座宋代石刻专题博物馆，国家二级博物馆。 - 馆藏文物 14000 余件，其中珍贵文物 550 件，一级文物 120 件。 - 完整复刻南宋社会百态，享有“雕刻在石头上的南宋” “石刻版清明上河图”之誉。 2. 龙脑桥 - 全国重点文物保护单位，位于泸县。 - 雨坛彩龙的龙头造型即依据龙脑桥的龙头设计： 额高、嘴短、双目突出可动，兼具威武与憨愚之态。 3. 合江荔枝与长江文化 - 合江荔枝有近 2000 年栽培历史。 - 杜甫“忆过泸戎摘荔枝”及“一骑红尘妃子笑”典故均与泸戎产荔枝相关。 - 长江国家文化公园（泸州段）建设正持续推进。 来源：央广网、新华网、泸州市人民政府官网。 -------------------------------------------------------- 六、资料来源汇总 -------------------------------------------------------- 1. 中国非物质文化遗产网（国家级非遗名录与项目介绍） 2. 泸州市人民政府官网（地方文化、非遗、文物数据） 3. 央广网（泸州非遗与文物总量报道） 4. 新华网（分水油纸伞等技艺报道） 5. 泸州老窖官网（1573 窖池群与酿造技艺） 6. 微信公众平台 / 新浪（先市酱油、泸县九大碗等补充资料
